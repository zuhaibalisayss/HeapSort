# Heap Sort & Priority Queues — Interactive Study

An interactive, single-page educational website that teaches Heap Sort and Priority Queues from scratch. Designed for use as both a classroom presentation and a self-learning resource.

## Features

- **13 comprehensive sections** covering everything from prerequisites to practice quizzes
- **Interactive Heap Sort visualizer** with step-by-step playback, pause/resume, and speed control
- **Interactive Priority Queue lab** supporting both max and min priority queues
- **Practice quiz** with 15 questions, immediate feedback, and score tracking
- **Presentation mode** with keyboard navigation (arrow keys, Escape)
- **Progress indicator** showing reading position
- **Responsive layout** for desktop, tablet, and mobile
- **Accessible** with keyboard navigation and sufficient color contrast

## Setup & Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Technologies

- React 18
- Vite
- Tailwind CSS v4
- TypeScript

## Sections

1. Introduction
2. Prerequisites (arrays, trees, index formulas)
3. Understanding Trees and Heaps
4. Max-Heap and Min-Heap
5. Heap Sort (with pseudocode and implementation)
6. Interactive Heap Sort Lab
7. Priority Queues
8. Interactive Priority Queue Lab
9. Heap Sort vs. Priority Queues (comparison)
10. Time Complexity (with interactive chart)
11. Common Mistakes
12. Practice Quiz
13. Final Revision and Key Takeaways

## Keyboard Shortcuts (Presentation Mode)

- **Right Arrow:** Next section
- **Left Arrow:** Previous section
- **Escape:** Exit presentation mode

## Design Principles

- No gradients, emojis, or icon libraries
- Solid colors only with a restrained palette
- Monospace font for code, arrays, and indices
- Clean typography with strong hierarchy
- All algorithm visualizations use correctly implemented algorithms
